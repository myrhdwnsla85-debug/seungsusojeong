# 승수 ♥ 소정 웨딩 식전 영상 (10분)

알파벳 **단어찾기 격자** 위에서 이름과 단어를 하나씩 찾아가며 두 사람의 이야기를 보여주는 식전 영상입니다.
색과 톤은 모바일 청첩장(`../index.html`)의 하늘색 종이 느낌을 그대로 가져왔습니다.

- 1920×1080, 30fps, **정확히 10:00** (사진 장면 길이가 자동으로 맞춰짐)
- 구성: 오프닝 → 01 신랑 → 02 신부 → 03 우리의 시작 → 04 함께한 계절들 → 05 여행 → 06 약속 → 07 그리고, 오늘(웨딩 촬영) → 엔딩(감사 인사 · 곧 예식 시작)

## 사진 바꾸는 법

1. 사진을 `public/photos/` 에 넣습니다.
2. `src/storyboard.ts` 에서 `ph("신랑 아기 때")` 같은 자리 표시를 `P("파일이름")` 으로 바꿉니다. (확장자 .jpg 기준)
3. 문구(`text`, `en`)도 같은 파일에서 자유롭게 고치면 됩니다.

장면 종류: `single`(사진 1장+문구), `duo`(2장), `trio`(3장), `full`(가로 사진 전체 화면), `gridcell`(격자에 구멍이 뚫리며 사진 + 단어 찾기), `text`(문구만)

## 음악

`public/audio/bgm.mp3` (청첩장 배경음악, 3:29)이 반복 재생됩니다. 다른 곡을 쓰려면 이 파일을 바꾸면 됩니다.
